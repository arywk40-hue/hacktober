Devpost submission must include all four components before the submission deadline:
1. Project description on your Devpost project page: Describe what you built, the problem it
solves, and how your solution works.
2. Source code/documentation: a link to a public GitHub repository containing your source
code and documentation. The repository must include a README with setup
instructions, prerequisites/dependencies, and instructions for running the project.
3. Demo video: 3 to 10 minutes on YouTube. Unlisted is fine. Private is not. The video must
show the project running and explain your approach. English audio or English subtitles
required.
4. Team information: all team members using their real full names. Every teammate must
have a Devpost account and must be added to the submission. Members who are not
added to the Devpost submission will not appear on the project page and may not
receive a certificate.
